# Project 1: Podcast Agent

> **DRAFT.** These instructions are still being written.

## Overview

Pick a podcast. Turn its transcripts into a vector database, then build a website with a custom AI interface that lets people search the podcast and discuss its content.

This project gets you started with the AI tools we'll use all term: Google Cloud, Vertex AI and Gemini.

## Team and repo

- **Team size:** 3.
- **Repo name:** `podcast-agent-team<NN>`, using your team number from [Project 0](Project_0_Git_Workflow.md). If your team changed, pick a new unused number; see [picking the repo name](../Guides/GitHub_New_Repo.md#1-pick-the-repo-name).
- Set up the repo with [Making a new repo](../Guides/GitHub_New_Repo.md): public, in the CSSE417-AI-Apps org, with `main` protected.
- Every change goes through [the PR workflow](../Guides/GitHub_PR_Workflow.md), with a teammate's approval.
